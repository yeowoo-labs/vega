# 보안 공지

Vega의 보안 결함을 고친 뒤의 요약이다. 공지마다 고친 커밋, 영향을 받는 판, 회귀 시험을 적는다. 결함을 잠그는 시험은 이 저장소의
`tests/`에 있다. 공지 번호는 Pure·aup·Vega가 함께 쓴다(Pure와 aup의 공지는 각 저장소의 `docs/security/`에 있다).

| 공지 | 제목 | 심각도 | 고친 커밋 |
|---|---|---|---|
| [PSA-2026-011](PSA-2026-011.md) | 아무 웹사이트나 `vega web`의 앱에 입력을 넣을 수 있었음 | 높음 | 832aab5 |
